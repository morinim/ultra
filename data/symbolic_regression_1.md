The target function is:

$$$
f(x,y) = x^2 + 2xy + \sin(x) - 3
$$$

Dataset characteristics:
- 200 uniformly sampled input pairs;
- $\(x,y \in [-3,3]\)$;
- columns: `x`, `y`, `target`;
- full floating-point precision;
- no measurement noise;

The dataset is suitable for an initial genetic programming test, particularly for assessing whether an algorithm can recover the original symbolic structure.
